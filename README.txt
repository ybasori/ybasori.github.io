YUSUF BASORI — FUTURISTIC PORTFOLIO
Desain baru bertema midnight, cyan dan violet; hero orbital animasi, tipografi modern, grid halus, proyek unggulan, detail pengalaman expandable, Hire me dan Available for opportunities.
Isi lengkap: 11 proyek, 7 posisi pekerjaan, keterampilan, pendidikan, 3 pelatihan, CV PDF dan portofolio PDF asli.
Animasi menghormati preferensi reduced motion. Konten tetap terbaca tanpa JavaScript; motion.js mengaktifkan carousel otomatis. Tidak memakai font eksternal.

PENERAPAN GITHUB PAGES
Cadangkan repository. Unggah seluruh isi paket ke folder sumber Pages, mengganti index.html/style.css dan menyertakan assets. Commit ke branch sumber Pages dan tunggu deployment. Tidak memerlukan npm/build. app.js lama tidak digunakan.

VERIFIKASI
Tautan lokal, isi, dan keberadaan aset diperiksa. Tampilan browser belum diuji pada sesi ini. Status Available sesuai permintaan; status pekerjaan mengikuti CV sumber.

PORTOFOLIO BERGERAK
11 kartu proyek dalam carousel otomatis setiap 4,5 detik. Navigasi panah, geser sentuh, tombol jeda, berhenti saat hover/fokus, tab tidak aktif, atau bagian proyek di luar layar. Preferensi reduced motion mematikan autoplay dan animasi. Pastikan motion.js ikut diunggah.

FADE IN / FADE OUT
Setiap bagian konten muncul saat masuk viewport dan memudar saat meninggalkan viewport; berulang saat scroll naik/turun. Kartu carousel juga memudar ketika keluar area tampilan. Keyboard focus, reduced motion, dan cetak menjaga konten terbaca. Unggah fade.js bersama motion.js, index.html, style.css, dan assets.
